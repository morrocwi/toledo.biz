## Binding rule

Until an entry is promoted to Toledo `registry/CANONICAL.json`, application code must preserve the status:

```text
new derivation/proposal
```

Do not display proposal equations to users as scientifically validated universal laws. Several entries are planning/governance heuristics or typed predicates.

When upstream promotion occurs, update this binding table to the canonical Toledo code and pin the tested upstream commit.
